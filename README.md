## 📁 Repository Structure

```
cisco-networking-labs/
├── README.md
├── 01-basic-router-config/
│   ├── README.md
│   ├── topology.png
│   ├── lab.pkt
│   └── configs/
└── ...
```

Each lab folder contains:
- 📝 `README.md`: objective, topology, steps, and results
- 🖼️ `topology.png`: network diagram screenshot
- 📦 `lab.pkt`: the Packet Tracer file
- ⚙️ `configs/`: device configurations as plain text

## 🚀 How to Use

1. Clone the repo: `git clone https://github.com/akhilesh-learner/cisco-networking-labs.git`
2. Open a lab's `.pkt` file in Cisco Packet Tracer
3. Follow the lab's README, or compare against the saved configs

## 💡 Skills Practiced

- 🔢 IPv4 addressing and subnetting
- 💻 Device configuration using Cisco IOS CLI
- 🔀 VLANs, trunking, and inter-VLAN routing
- 🛣️ Static and dynamic routing
- 🔍 Troubleshooting with `ping`, `traceroute`, and `show` commands
